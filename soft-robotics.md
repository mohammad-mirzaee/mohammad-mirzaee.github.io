# Soft Robotics & Biomechanics

My research in this domain focuses on the computational modeling of flexible structures and biological tissues, bridging the gap between high-fidelity finite element analyses and real-time dynamic applications.

## Fin Ray Inspired Soft Robotic Gripper

This multi-phase project explores the mechanical behavior and real-time control of biologically inspired soft gripping mechanisms.

* **Finite Element Modeling:** Conducted in-depth structural finite element analyses of the fin ray effect to understand deformation under load, evaluating structural responses and troubleshooting complex contact formulations.
* **Kinetostatics Analysis:** Applied the Chained Beam Constraint Model to mathematically capture the static kinematics of the highly compliant gripper mechanism.
* **Real-Time Dynamics:** Developed dynamic modeling of the fin ray soft tissue using the PCS method. To document these findings, I write MATLAB scripts to process the resulting simulation datasets and execute curve fitting, ultimately generating IEEE LaTeX-styled figures for comprehensive engineering thesis reports.

## Traumatic Brain Injury Simulation

This project centers on biomedical impact modeling to create efficient diagnostic assessment tools.

* **SIMon FEHM Simulation:** Utilized the Simulated Injury Monitor Finite Element Head Model to analyze the complex mechanical responses of brain tissue under extreme traumatic loading conditions.
* **Lumped Parameter Modeling:** Developed a corresponding lumped parameter model to translate the computationally heavy simulation data into a rapid assessment tool, allowing for quicker diagnostic insights.
